# 🌱 Community Surplus

Community Surplus is a full-stack web application that helps people share
extra food and household resources with their local community.

## ✨ Features

- User Registration and Login
- JWT Authentication
- User Profile
- Share Surplus Resources
- View Available Resources
- Search Resources
- Filter Resources by Category
- Find Nearby Resources
- Request Resources
- My Requests
- My Resources
- Accept / Reject Resource Requests
- Dashboard
- Responsive Mobile Navbar

## 🛠️ Technologies Used

### Frontend
- React
- React Router
- Vite
- CSS

### Backend
- Node.js
- Express.js
- JWT
- bcrypt

### Database
- PostgreSQL
